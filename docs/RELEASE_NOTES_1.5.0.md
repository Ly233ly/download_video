## 主要改进

- 修复微信视频号只能拿到低清转码的问题：“原始视频”只逐字节保留非空 `encfilekey` 与 `token`，不再携带 `basedata`、`sign`、`svrnonce` 等转码上下文；明确质量档继续保留其签名查询和质量标志。
- 修复开启 VPN 后再开始视频号捕获会导致视频号无法访问的问题：捕获代理现在继承 Windows PAC/WPAD 或手动 HTTP/Mixed 上游，普通 HTTP、HTTPS CONNECT 和目标视频号 TLS 流量按各自 URL 正确选路。PAC 预检失败时不会改写现有系统代理。
- 修复浏览器扩展候选较多时，点击底部候选会自动滚回列表顶部的问题。候选选中、质量切换和批量状态重绘会保持原列表位置，列表缩短时安全钳制；首次进入和跟随最新项仍正常滚到底部。
- 修复覆盖升级时 Windows 证书删除工具偶发挂住并遗留孤儿进程的问题。没有活动捕获代理租约时直接复用现有可信证书；确需清理时，证书命令和安装器等待都有明确超时，失败会保留旧安装。

## 兼容性

- 数据库结构保持为 6，浏览器扩展协议保持为 1。
- 覆盖安装会保留现有下载任务、浏览器配对、软件设置、网站规则和用户数据库。
- Chrome 与 Firefox 扩展版本同步升级为 1.5.0。
- FFmpeg、yt-dlp 和 Deno 仍全部随发行包在本机运行，不上传媒体到第三方服务。

> 建议直接运行“一键安装.exe”覆盖升级。升级完成后请在扩展管理页重新加载一次开发版扩展，使 1.5.0 前端脚本立即生效。
