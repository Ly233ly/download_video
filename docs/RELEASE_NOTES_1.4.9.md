## 主要改进

- 修复视频号捕获的代理恢复问题：当系统代理被其他程序禁用（ProxyEnable 被改为 0）但残留本机代理地址时，停止捕获不再误报“系统代理已被其他程序修改、未覆盖当前设置”，程序会安全恢复捕获前的系统代理。
- 修复“修复代理冲突”按钮在系统代理被禁用时无作为的问题：现在会识别并清除失效残留的本机代理，之后可以正常开始捕获。
- 修复视频号捕获进入“需要人工恢复”状态后无法退出的问题：只要当前没有正在运行的其他系统代理，再次点击“开始捕获”会直接恢复正常，无需重启程序。

## 兼容性

- 数据库结构保持为 6，浏览器扩展协议保持为 1。
- 覆盖安装会保留现有下载任务、浏览器配对、软件设置和用户数据库。
- Chrome 与 Firefox 扩展版本同步升级为 1.4.9。

> 建议直接运行“一键安装.exe”覆盖升级。升级完成后如浏览器扩展没有立即刷新，可在扩展管理页重新加载一次扩展。
