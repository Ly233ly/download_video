# 1.3.0 发布验证记录

日期：2026-07-26
状态：当前源码自动测试、冻结运行时、隔离安装器、发行构建和当前电脑覆盖安装通过；真实微信最终媒体闭环待执行，因此只允许作为预发布版

## 已通过

- Python 全量：158 项 unittest 通过。
- 视频号桥：Node 测试通过，覆盖 feed 规范化、动态质量、卡片/富文本标题、零密钥、DOM 安全编码、内部 API 方法身份、原操作栏/悬浮入口、当前质量选择和 objectId/variantId 提交；页面不执行远程下载、解密或 Eagle。
- Python/JavaScript 语法、Chrome/Firefox 清单 JSON 解析通过。
- `installer/Setup.cs` 与 `launcher/Launcher.cs` 使用 Windows C# 编译器独立编译通过。
- 视频号确定性纵向闭环：本机生成视频 → 加密前缀 → 回环 HTTP 下载 → 流式解密 → FFmpeg/ffprobe 验证 320×240 视频 → `completed_local`。
- 安全回归覆盖每机证书、原根证书下叶配置轮换、页面/资源目标 TLS、非目标 CONNECT、普通 HTTP 透明转发、完整 WinINET/二进制快照、外部修改保护、孤儿恢复、启动中途失败恢复、退出时代理优先恢复、压缩炸弹、500 项候选上限、连接上限、跨域 Cookie 阻断和秘密零落盘。资源模块回归还证明 `finder*` 改写保持原异步返回值，并把页面及 ES 模块依赖全部绑定到当前捕获会话缓存键。
- 主窗口在最低高度下可纵向滚动到标签详情、操作区和全局底栏，Treeview/Combobox 保持自身滚轮；媒体、视频号、IDM 和网站规则四类列表均有刷新与安全清理操作，清理不删除文件、不动 Eagle、不影响活动任务。
- 当前发行包的冻结后端健康门通过：版本 1.3.0、协议 1、schema 5、`desktop_ffmpeg`、FFmpeg/ffprobe/yt-dlp/Deno 就绪、视频号默认关闭、bridge 哈希有效；冻结 IDM 接收模式只写入一条测试任务。
- 当前隔离安装器四路径通过：全新安装资产齐全，升级轮换配对凭据并清理旧文件，故障注入恢复原可执行文件和标记，卸载只移除测试安装与测试注册表状态。
- 当前电脑已用最终安装器覆盖安装；在线健康、系统代理 `127.0.0.1:7890` 和安装载荷哈希核对通过。
