## 主要改进

- 新增微亮与深色双主题，默认使用低眩光的微亮灰紫界面；可在侧栏底部切换，并自动记住选择。
- 全面统一按钮、导航、候选卡片、缩略图槽和质量选择器的圆角、间距、边框与交互状态，减少界面割裂感。
- 重做视频号下载质量选择器，使列表样式与应用主题一致，并随主题即时换色。
- 去除应用内重复的“下载中转站”标题，Windows 原生标题栏直接显示“下载中转站 v1.4.7”，同时跟随当前主题。
- 延续并整合此前的界面性能优化，避免主题切换、窗口缩放和列表刷新引入额外回调或明显卡顿。

## 兼容性

- 数据库结构保持为 6，浏览器扩展协议保持为 1。
- 覆盖安装会保留现有下载任务、浏览器配对、软件设置和用户数据库。
- Chrome 与 Firefox 扩展版本同步升级为 1.4.7。

> 建议直接运行“一键安装.exe”覆盖升级。升级完成后如浏览器扩展没有立即刷新，可在扩展管理页重新加载一次扩展。
