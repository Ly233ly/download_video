# 安装、更新、故障排查与卸载

本文只适用于当前版本。

## 安装

1. 下载并解压 `download-transfer-station-1.5.0-windows-x64.zip`。
2. 双击 `一键安装.exe`，选择“一键安装”。
3. 安装器复制程序文件、创建快捷方式和卸载入口，然后启动下载中转站。
4. 安装器会打开浏览器扩展目录。进入 Chrome 或 Edge 扩展管理页，开启“开发者模式”，选择“加载已解压的扩展程序”。
5. 选择安装器打开的 `chrome-extension` 文件夹。

浏览器的最后一次扩展确认必须由用户完成，安装器不会绕过浏览器安全边界。

安装包已包含 FFmpeg、FFprobe、yt-dlp、Deno、Python 运行时和 Tcl/Tk，不需要另外安装这些组件。

## IDM 保护

- IDM 对应病毒检查设置为空时，安装器可以配置本程序 hook。
- IDM 已指向本程序旧安装位置时，可以更新为当前路径。
- IDM 已指向其他杀毒软件或无法确认归属的程序时，安装器不得覆盖。
- 卸载时只有当前设置仍指向本程序，才恢复安装前值。

## 正常使用

### 浏览器

打开并播放目标内容，点击扩展图标，在候选列表中核对标题、预览和质量，然后选择“仅下载”或“导入 Eagle”。任务会出现在桌面“下载任务”页面。

### 微信视频号

打开桌面“微信视频号”页面并点击“开始捕获”。首次使用时必须由用户亲自核对并确认名称为“下载中转站 微信视频号本机捕获根证书”的 Windows 安全警告。

在 Windows 微信客户端重新进入并播放目标内容。原操作栏会出现“下载”，悬停可以选择其他实际质量；只有当前 feed 提供有效原始凭据时才显示“原始视频”。

完成选择后可以停止捕获，已经提交的任务会继续运行。

### IDM 与 Eagle

- Eagle 正在运行时，完成文件会导入当前资源库。
- Eagle 未运行时，任务保持等待；启动 Eagle 后自动继续或手动重试。
- 无来源 IDM 文件仍会导入，不会猜测网址。
- “仅下载”文件默认位于 `%USERPROFILE%\Downloads\下载中转站\已完成`。
- 仅下载完成后可以从任务卡补导 Eagle，不需要重新下载。

## VPN 与代理

保持 VPN 运行即可开始视频号捕获。程序会继续使用 Windows 当前 HTTP/Mixed 代理，或者通过 WinHTTP 按 URL 解析 PAC/WPAD。

如果启动提示 PAC 无法解析或代理类型不支持：

1. 在 VPN 软件中启用 HTTP/Mixed 端口。
2. 在下载中转站网络设置中选择手动代理。
3. 填写类似 `127.0.0.1:7890` 的 HTTP/Mixed 地址。

不要填写纯 SOCKS 端口。预检失败不会改写当前 Windows 代理。

## 常见问题

### 扩展显示助手离线

确认桌面程序正在运行。如果扩展刚更新，在扩展管理页点击“重新加载”。仍未连接时，在桌面设置中查看六位配对码并手动配对。

### 视频正常播放但没有候选

刷新来源页并重新播放，再打开扩展。对于信息流页面，先让目标播放器进入视口。无法归属内容的技术分片默认不会显示为可下载媒体。

### 视频号没有候选

确认捕获状态为“等待微信”或“捕获中”，然后退出当前视频并重新进入播放。若页面无法唯一确认当前内容，程序会拒绝创建候选而不是猜测。

### 开启 VPN 后视频号无法访问

停止捕获，确认 VPN 提供 HTTP/Mixed 端口，再按“VPN 与代理”设置上游。不要关闭 VPN 后留下失效的系统代理地址。

### 任务一直等待 Eagle

打开 Eagle 并进入目标资源库，然后点击任务重试。程序只调用 Eagle 本地 Web API，不直接修改资源库目录。

### 下载完成后在哪里

任务详情显示完整路径，并提供“打开所在文件夹”。如果选择了导入后删除，只有 Eagle 成功和文件归属校验通过后，本程序创建的副本才会删除。

## 覆盖更新与回滚

重新运行新版 `一键安装.exe` 即可覆盖更新。安装器会保留用户数据库、任务、网站规则、浏览器配对和可信的程序证书。

更新前旧程序目录会成为临时备份。新后台必须在限定时间内通过版本、数据库、扩展协议和媒体工具健康检查；失败时恢复旧目录并重新启动旧程序。

如果存在活动视频号捕获，更新会先请求旧程序恢复代理和停止捕获。外部证书工具或清理进程超时会被终止，更新中止，不会继续替换程序。

稳定自动更新还要求 RSA 签名、ZIP 大小和 SHA-256 全部匹配。缺少有效签名时客户端会拒绝更新。

## 卸载

从 Windows“已安装的应用”或开始菜单运行卸载程序。

卸载程序只删除能够验证归属的程序文件、快捷方式、注册表项、视频号证书和本程序拥有的代理设置。它不会删除：

- 用户下载的视频
- IDM 原文件
- Eagle 内容
- 其他软件的代理设置
- 用户数据库中的历史记录和规则

浏览器中手动加载的扩展需要用户在扩展管理页自行移除。
