# 安装、更新、故障排查与卸载

本文适用于 1.6.3 安装、更新、故障排查与卸载流程。发行状态、文件和 SHA-256 见 [1.6.3 发布验证](RELEASE_VERIFICATION_1.6.3.md)。

## 安装

1. 从 [GitHub Release v1.6.3](https://github.com/Ly233ly/download_video/releases/tag/v1.6.3) 下载并解压 `liudi-downloader-1.6.3-windows-x64.zip`，按 [1.6.3 发布验证](RELEASE_VERIFICATION_1.6.3.md) 核对大小和 SHA-256。
2. 双击 `留底安装器.exe`，选择“一键安装”。
3. 留底安装器复制程序文件、创建快捷方式和卸载入口，然后启动留底桌面端。
4. 安装器会打开浏览器扩展目录。进入 Chrome 或 Edge 扩展管理页，开启“开发者模式”，选择“加载已解压的扩展程序”。
5. 选择安装器打开的 `chrome-extension` 文件夹。

浏览器的最后一次扩展确认必须由用户完成，安装器不会绕过浏览器安全边界。

安装包已包含 FFmpeg、FFprobe、yt-dlp、Deno、Python 运行时和 Tcl/Tk，不需要另外安装这些组件。

## IDM 保护

- IDM 对应病毒检查设置为空时，安装器可以配置本程序 hook。
- IDM 已指向本程序旧安装位置时，可以更新为当前路径。
- IDM 已指向其他杀毒软件或无法确认归属的程序时，安装器不得覆盖。
- 卸载时只有当前设置仍指向本程序，才恢复安装前值。

## 正常使用

### 浏览器

打开并播放目标内容，点击扩展图标，在候选列表中核对标题、预览和质量。Eagle 可用时可以选择“仅下载”或“导入 Eagle”；没有安装或没有启动 Eagle 时，主按钮自动显示“下载到电脑”。任务都会出现在桌面“下载任务”页面。

### 微信视频号

打开留底桌面端“微信视频号”页面并点击“开始捕获”。首次使用时必须由用户亲自核对并确认名称为“留底下载器 微信视频号本机捕获根证书”的 Windows 安全警告。

在 Windows 微信客户端重新进入并播放目标内容。原操作栏会出现“下载”，悬停可以选择其他实际质量；只有当前 feed 提供有效原始凭据时才显示“原始视频”。没有 Eagle 时该按钮仍会正常下载，并在电脑中保留文件。

完成选择后可以停止捕获，已经提交的任务会继续运行。

### IDM 与 Eagle

- Eagle 不是浏览器和视频号下载的必需软件；未安装 Eagle 时仍可使用下载、合并、校验、停止、重试、打开文件和清理记录。
- Eagle 正在运行时，完成文件会导入当前资源库。
- IDM 文件已经由 IDM 下载完成，因此 Eagle 未运行时只有 IDM 导入任务保持等待；原文件不会删除，启动 Eagle 后自动继续或手动重试。
- 无来源 IDM 文件仍会导入，不会猜测网址。
- “仅下载”文件默认位于 `%USERPROFILE%\Downloads\留底下载器\已完成`。升级用户若已存在旧目录且尚未创建新目录，会继续使用旧目录，不会搬移或删除文件。
- 仅下载完成后可以从任务卡补导 Eagle，不需要重新下载。

## VPN 与代理

保持 VPN 运行即可开始视频号捕获。程序会继续使用 Windows 当前 HTTP/Mixed 代理，或者通过 WinHTTP 按 URL 解析 PAC/WPAD。

如果启动提示 PAC 无法解析或代理类型不支持：

1. 在 VPN 软件中启用 HTTP/Mixed 端口。
2. 在留底桌面端网络设置中选择手动代理。
3. 填写类似 `127.0.0.1:7890` 的 HTTP/Mixed 地址。

不要填写纯 SOCKS 端口。预检失败不会改写当前 Windows 代理。

## 常见问题

### 扩展显示助手离线

确认留底桌面端正在运行。如果扩展刚更新，在扩展管理页点击“重新加载”。仍未连接时，打开扩展设置并点击“自动连接留底桌面端”。首次安装和同一扩展的连接恢复都不需要输入配对码；若提示未找到软件，请先启动或修复安装留底下载器。

### 视频正常播放但没有候选

刷新来源页并重新播放，再打开扩展。对于信息流页面，先让目标播放器进入视口。无法归属内容的技术分片默认不会显示为可下载媒体。

### 视频号没有候选

确认捕获状态为“等待微信”或“捕获中”，然后退出当前视频并重新进入播放。新版页面脚本只有在重新进入页面后才会注入。若出现“未能确认当前视频”、候选存在但没有任务，或连续刷视频后偶发失败，按 [微信视频号技术文档](WECHAT_CHANNELS.md) 的“诊断顺序”检查；程序会拒绝歧义内容而不是猜测。

### 开启 VPN 后视频号无法访问

当前版本会忽略可能切断全部捕获上游的独立 `ProxyOverride=*`，同时保留明确的本地域名和网段绕过。若仍无法访问，立即停止捕获，确认 VPN 提供 HTTP/Mixed 端口，再按“VPN 与代理”设置上游。不要关闭 VPN 后留下失效的系统代理地址；恢复检查见 [微信视频号技术文档](WECHAT_CHANNELS.md)。

### 任务一直等待 Eagle

这通常是 IDM 导入任务，或过去选择了 Eagle 导入的媒体任务。原文件仍然安全保留，浏览器和视频号的新下载不受影响。需要归档时打开 Eagle 并进入目标资源库，然后点击任务重试；不需要 Eagle 时可直接使用扩展的“下载到电脑”。程序只调用 Eagle 本地 Web API，不直接修改资源库目录。

### 下载完成后在哪里

任务详情显示完整路径，并提供“打开所在文件夹”。如果选择了导入后删除，只有 Eagle 成功和文件归属校验通过后，本程序创建的副本才会删除。

### 如何清理临时文件和预览

打开“设置 → 文件管理”。“程序缓存”会显示临时下载、任务预览和旧版日志的占用；可立即手动清理，也可设置自动清理天数。设为 `0` 表示关闭自动清理。

该操作不会删除 `%USERPROFILE%\Downloads\留底下载器\已完成`、兼容使用的旧版下载目录、活动任务、IDM 原文件或用户文件。

## 覆盖更新与回滚

重新运行新版 `留底安装器.exe` 即可覆盖更新。安装器会保留用户数据库、任务、网站规则、浏览器连接认证状态和可信的程序证书。

更新前旧程序目录会成为临时备份。新后台必须在限定时间内通过版本、数据库、扩展协议和媒体工具健康检查；失败时恢复旧目录并重新启动旧程序。

如果存在活动视频号捕获，更新会先请求旧程序恢复代理和停止捕获。外部证书工具或清理进程超时会被终止，更新中止，不会继续替换程序。

### 从 1.6.2 升级

1.6.2 仍使用旧 RSA 清单，不能自动认识 GitHub 更新方式。请从正式 Release 手动下载 1.6.3，运行一次 `留底安装器.exe` 完成覆盖；数据库、任务、设置、网站规则和代理状态会保留。

从 1.6.3 开始，可打开“设置 → 关于与更新 → 检查更新”。软件只接受本项目 GitHub 正式 Release，校验固定 Windows 资产的 GitHub SHA-256、声明/实际大小及安全 ZIP 结构后才启动安装器。GitHub API 暂时限流时会提示稍后重试，不会绕过校验或改用第三方下载站。

## 卸载

从 Windows“已安装的应用”或开始菜单运行卸载程序。

卸载程序只删除能够验证归属的程序文件、快捷方式、注册表项、视频号证书和本程序拥有的代理设置。它不会删除：

- 用户下载的视频
- IDM 原文件
- Eagle 内容
- 其他软件的代理设置
- 用户数据库中的历史记录和规则

浏览器中手动加载的扩展需要用户在扩展管理页自行移除。
