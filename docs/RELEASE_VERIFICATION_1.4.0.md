# 1.4.0 发布验证报告

验证日期：2026-07-26

发布类型：预发布候选

## 本轮范围

- 桌面主窗口统一为“下载任务 / 视频号 / IDM 导入 / 设置 + 诊断”的左侧导航，并将媒体任务、IDM 记录和设置职责清晰分区。
- 下载任务、视频号和 IDM 导入均按真实状态限制停止、重试、打开位置、打开可靠来源和补导等动作；合并与校验阶段不提前显示 100%。
- 浏览器扩展保持单一应用根和“媒体 / 任务”两级导航，补齐任务预览、真实进度、大小、错误、输出路径与状态适用动作。
- 托盘仍由 Windows Forms 宿主管理，只调整“显示窗口 / 唤醒处理”等入口文案，没有把窗口过程迁入 Python。
- 桌面、扩展和托盘共用暖灰白、低对比度、克制留白的视觉语言；没有新增第三方 Python 运行时依赖。
