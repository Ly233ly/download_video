## 主要改进

- 全面优化 Tk 桌面界面的刷新、滚动、缩放和后台任务调度，减少卡顿、残影与操作延迟。
- 修复媒体、IDM、视频号、网站规则以及浏览器扩展列表中部分记录无法清理的问题，并支持单条安全清理。
- 浏览器扩展可跟随通用单页应用地址变化、自动连播和独立窗口中的当前网页，无需手动刷新。
- 优化视频号候选归组、预加载过滤、证书预检与代理恢复，降低大量候选造成的卡顿。
- Windows 原生标题栏与深色应用外壳统一，保留系统窗口控制、缩放边框和贴边布局。
- 修正 v1.4.5 GitHub 发布说明的中文编码，发布页不再显示问号。
